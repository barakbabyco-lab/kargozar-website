# اپلیکیشن اندروید کارگزار

این پوشه شامل نسخه اولیه اپلیکیشن مشتریان کارگزار با Flutter است.

## وضعیت فعلی
- اسکلت مستقل اپلیکیشن اندروید در مسیر `mobile/`
- رابط کاربری فارسی و راست‌چین
- صفحه خانه، فهرست خدمات، ثبت درخواست آزمایشی، پیگیری و حساب کاربری
- داده‌های فعلی نمونه هستند؛ هنوز به سرور یا پایگاه داده واقعی متصل نشده‌اند.

## اجرا
Flutter SDK را نصب کنید، سپس در همین پوشه اجرا کنید:

```bash
flutter pub get
flutter run
```

## مسیر توسعه
1. تأیید تجربه کاربری و فهرست خدمات
2. طراحی API و دیتابیس مرکزی
3. پیاده‌سازی احراز هویت و ذخیره امن مدارک
4. اتصال اپلیکیشن به API
5. تست، ساخت APK و آماده‌سازی انتشار

**مهم:** تا زمان راه‌اندازی زیرساخت امن، اطلاعات واقعی هویتی یا اسناد مشتریان را در نسخه آزمایشی وارد نکنید.
