# اپلیکیشن اندروید کارگزار

اپلیکیشن مشتری کارگزار با Flutter ساخته می‌شود.

## وضعیت فعلی
- رابط اولیه خانه، فهرست خدمات، درخواست‌ها و حساب کاربری در `lib/main.dart` قرار دارد.
- فرم ثبت درخواست فعلاً نمایشی است و اطلاعات را ذخیره یا ارسال نمی‌کند.
- کلاینت پایه API نسخه `v1` در `lib/core/network/kargozar_api_client.dart` اضافه شده است.
- تا زمان آماده‌شدن سرور و احراز هویت، کلاینت API به رابط کاربری متصل نشده است.
- هیچ‌گاه اطلاعات واقعی مشتری یا مدارک هویتی را در نسخه آزمایشی وارد نکنید.

## پیکربندی API
پس از استقرار بک‌اند، نشانی ریشه API را هنگام اجرا یا ساخت تعیین کنید. نشانی باید شامل پیشوند نسخه باشد:

```bash
flutter run --dart-define=API_BASE_URL=https://api.example.com/api/v1
```

برای ساخت APK آزمایشی:

```bash
flutter build apk --debug
```

توکن دسترسی پس از تأیید OTP با `flutter_secure_storage` در فضای امن سیستم‌عامل نگهداری می‌شود. در آغاز برنامه باید `await api.restoreAccessToken()` اجرا شود؛ سپس درخواست‌های نیازمند ورود می‌توانند از نشست بازیابی‌شده استفاده کنند. متد `verifyOtp` توکن پاسخ را ذخیره و `logout` پس از موفقیت سرور آن را پاک می‌کند. کلید پیامک یا کلید خصوصی هرگز نباید داخل سورس یا فایل‌های قابل انتشار قرار بگیرد.
