# تنظیم نشانی API برای اپ اندروید

اپ Flutter نشانی API را در زمان ساخت از متغیر کامپایل‌تایم `API_BASE_URL` می‌خواند. مقدار باید ریشه نسخه‌بندی‌شده API باشد، برای نمونه:

`https://api.example.ir/api/v1`

نشانی عملیاتی اپ کارگزار `https://api.barakmod.ir/api/v1` است. در صورت تنظیم Repository variable با نام `KARGOZAR_API_BASE_URL`، مقدار آن جایگزین این پیش‌فرض می‌شود.

## تنظیم در GitHub

در مخزن GitHub به مسیر Settings → Secrets and variables → Actions → Variables بروید و یک Repository variable با نام `KARGOZAR_API_BASE_URL` بسازید. مقدار آن باید نشانی HTTPS واقعی بک‌اند به‌همراه `/api/v1` باشد.

این مقدار محرمانه نیست؛ کلید پیامک، رمز دیتابیس، APP_KEY و هر credential دیگری نباید در Variables یا سورس اپ قرار بگیرند. اطلاعات محرمانه فقط در GitHub Secrets برای workflowهای سرور یا در فایل محیطی امن هاست نگهداری شوند.

Workflow اندروید مقدار این Variable را در ساخت APK آزمایشی و نسخه Release به‌صورت `--dart-define=API_BASE_URL=...` تزریق می‌کند. اگر Variable تنظیم نشده باشد، آدرس عملیاتی بالا به‌عنوان پیش‌فرض استفاده می‌شود. گردش کار ساخت APK پیش از تولید فایل، دسترسی HTTPS و پاسخ JSON بک‌اند را بررسی می‌کند و در صورت برقرار نبودن اتصال، ساخت را متوقف می‌کند تا APK معیوب تحویل نشود.

## پیش از تنظیم Variable

1. بک‌اند Laravel روی سرور مقصد مستقر و دامنه `api.barakmod.ir` به پوشه `public` آن متصل شود.
2. HTTPS معتبر و مسیر `/api/v1` از اینترنت قابل دسترس باشد.
3. endpointهای خدمات، OTP و ثبت/فهرست درخواست‌ها با داده آزمایشی بررسی شوند.
4. فقط پس از تأیید این موارد، مقدار واقعی در Repository Variables ثبت و workflow دوباره اجرا شود.

## نشانی امن تصاویر اپلیکیشن

تصاویر نهایی ۱۰ دسته خدمات، ۹ ماژول همراه کسب‌وکار و ۵ بنر با نام فایل‌های ثابت از متغیر `KARGOZAR_ASSETS_BASE_URL` بارگذاری می‌شوند. این مقدار باید فقط ریشه HTTPS پوشه تصاویر باشد، بدون اسلش انتهایی؛ برای نمونه ساختاری مانند `https://static.example.ir/kargozar-assets/final` (این نشانی صرفاً نمونه است). مقدار واقعی را پس از فعال‌سازی SSL روی دامنه تصاویر در GitHub Repository Variables ثبت کنید. اپلیکیشن برای تصاویر نیز از HTTP ناامن استفاده نمی‌کند.
